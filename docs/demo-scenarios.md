# M01~M08 대화·배차·지도 시연

Python 가상환경은 README의 설치 절차를 따릅니다. 루트에서 터미널 두 개로 실행합니다.

```sh
npm run agent:demo
npm run dev
```

본사물류운영자 화면에서 M01~M08 버튼을 누르면 정해진 요청을 전송합니다. 일반 채팅 입력도 날짜·지점·차량 수를 처리합니다. 기준일은 2026-09-11로 고정합니다. 자유로운 자연어 처리나 실제 TMS 최적화 성능을 검증하는 시연이 아닙니다.

| 시나리오 | 입력·답변                                                   | 확인할 화면                                                                                 |
| -------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| M01      | 정상 배차 버튼 또는 `2026-09-11 마포 서대문 은평 배차해줘`  | 주문 6건 자동 선택, 차량 4대 결과·지도 경로                                                 |
| M02      | 배송일 누락 버튼 → `2026-09-11로 배차`                      | 배송일만 재질문, 같은 요청 ID로 완료. 차량 수는 생략 가능                                   |
| M03      | 주소 확인 버튼 → `서울특별시 마포구 월드컵로 212 정문 확인` | 확인 전 배차 0회·경로 없음, 확인 후 결과. 다시 M03을 시작하면 다시 주소 확인                |
| M04      | 부적합 차량 버튼                                            | 보관유형·적재량 오류, 배차 0회·경로 없음                                                    |
| M05      | 조회 시간 초과 버튼                                         | 배차 1회, 통신 재시도 3회와 대기 응답 3회로 총 조회 6회 후 timeout. 자동 재전송 없음        |
| M06      | 일부 미배정 버튼                                            | 차량 3대·배정 5건·미배정 1건. ETA·거리·시간 미제공                                          |
| M07      | API 키 요구 버튼                                            | 모델·배차 실행 전 차단, 대화의 합성 키 값은 `***`                                           |
| M08      | 금지 Tool 인자 버튼                                         | 대체 모델의 endpoint·header·appKey·runtime_context 인자를 실제 검증 계층에서 차단, 배차 0회 |

시연 서비스는 각 새 대화에 별도 DispatchAgent와 Backend를 만듭니다. 요청 추출·CSV 조회·Tool 실행·좌표 검증·차량 검증·결과 검증은 실제 코드로 처리합니다. M03·M05·M06의 외부 응답과 M08의 모델 Tool 출력만 고정 대역으로 재현합니다. M05는 운영 Tool과 같은 폴링 함수를 사용하고 대기 시간만 생략합니다. 화면의 호출 횟수는 해당 Backend에서 집계한 값입니다.

지도는 현재 요청에서 확인된 좌표와 배차 방문 순서를 직선으로 연결합니다. 실제 도로 경로가 아니며 ETA·거리·시간을 계산해 채우지 않습니다. 배송 품목·중량은 해당 Python 요청에서 조회한 CSV 주문을 사용합니다. 새 대화나 차단 시 이전 경로를 지우고, 수동 선택 변경 시 결과를 초기화합니다.

`--scenarios`가 없는 일반 API는 기존 계약과 실행 모드를 유지합니다. 시연 기능은 외부 API·키·모드·runtime_context를 클라이언트가 지정하는 기능이 아닙니다. 합성 응답을 사용하는 시연 서버는 항상 offline입니다.

## 검증

```sh
npm run test:scenarios
cd agent
USE_MOCK=1 MODEL_MODE=offline .venv/bin/python -m pytest -q
```

브라우저 검증 명령은 필요하면 Vite와 시연 서버를 시작합니다. 8000 포트에 일반 서버가 이미 떠 있으면 종료하고 시연 서버로 다시 실행하세요. 테스트는 health의 offline·scenarios 값을 확인한 후 메시지를 전송합니다.

Python 검증은 요청 격리·호출 횟수·차단·마스킹을, 브라우저 검증은 선택값·결과표·지도 표시를 함께 확인합니다. 실제 LLM·TMAP·TMS 검증과 운영 인증·기사 권한·재배차는 포함하지 않습니다.
