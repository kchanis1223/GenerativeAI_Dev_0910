# main 정리 기록 (2026-09-11)

현재 v2 실행과 문서 링크, 테스트·패키지 의존성을 기준으로 정리한다. 삭제한 파일은 Git 이력에 남는다.

## 산출물

- 사용하지 않는 JayeonSans OTF·TTF·WOFF 6개를 삭제하고 실제 사용하는 WOFF2 2개는 유지했다.
- 현재 문서에서 참조하지 않는 화면 이미지 6개, 이전 설계서 DOCX 4개와 초기 PDF를 삭제했다. 현재 v2, 사용자 수정 원본, 문서에 연결된 화면 이미지 3개는 유지했다.
- 사용하지 않는 SVG 파비콘, 로고 추출용 일회성 스크립트, 내용이 채워진 폴더의 `.gitkeep` 3개를 삭제했다.
- 삭제한 22개 파일의 합계는 25,609,837바이트(약 24.4 MiB)다. 저장소의 과거 커밋 용량은 줄이지 않는다.

## 유지하는 파일

- `data/`는 Vue용 CSV이며 `agent/data/`의 Python CSV와 필드 구성이 다르다.
- `agent/badaro/data/`와 `tools/mock_responses/`는 설치한 Python 패키지에서 사용하는 데이터다. 원본과의 일치 여부를 테스트한다.
- 지오코딩 응답·검증 보고서와 `docs/api/` 응답은 좌표와 API 매핑을 확인하는 근거로 유지한다.
- 프론트 목업의 24개 API 계약·배차 계산, 현재 지도·채팅·센터 조회, 회귀 테스트는 유지한다.
- `notebooks/.gitkeep`는 아직 비어 있는 실습 폴더를 보존한다.

## Python 코드

- Agent에 등록되지 않은 모델 분기와 장기 저장 모듈, 미제공 확정·취소 Tool의 감사 저장 분기를 제거했다.
- 실제 Tool 호출 로그와 마스킹, 재시도 제한, 입력·배차 결과 검증은 유지했다.
- 이전 문장 대조 검증기·권한 호환 함수와 관련 회귀 테스트는 삭제하지 않았다. 현재 Agent에 등록되지 않은 코드임을 구분했다.
