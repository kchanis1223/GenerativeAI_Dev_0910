## Python 호환 여부

검증 대상은 [PR #29](https://github.com/kchanis1223/GenerativeAI_Dev_0910/pull/29)가 병합된
main 커밋 `598e290a00cde6b5351b548a424166846f76bd99`의 `agent/badaro/schemas/models.py`입니다.
PR #33의 검증 코드로 이 모델과 PR #32의 CSV를 다시 검사해 아래 결과가 일치함을 확인했습니다.
같은 모델을 지정한 `tests/test_sample_data.py` 테스트 11개도 통과했습니다.

| 입력                     | Order      | Vehicle  | 판정                                |
| ------------------------ | ---------- | -------- | ----------------------------------- |
| CSV 행 그대로            | 0/40 통과  | 0/5 통과 | 필드명·리스트 형식 불일치           |
| 명시적 필드·단위 변환 후 | 40/40 통과 | 5/5 통과 | 모델 검증 통과, 조회 Tool 연결 필요 |

| CSV 필드                       | Python 모델                                          | 변환                                                    |
| ------------------------------ | ---------------------------------------------------- | ------------------------------------------------------- |
| orderId / branchId             | order_id / destination_id                            | 문자열 ID 유지                                          |
| itemName / deliveryWeight      | items / weight_kg                                    | 한 품목의 OrderItem 목록, kg 유지                       |
| deliveryVolume                 | volume_m3                                            | 숫자 변환, m³ 유지                                      |
| itemType                       | storage_type                                         | 활어→live, 냉장→refrigerated, 냉동→frozen, 일반→ambient |
| priority                       | priority                                             | CSV에 normal 명시                                       |
| serviceTime                    | service_seconds                                      | 분 × 60                                                 |
| deliveryDate + closeTime       | deadline                                             | 마감일시, Asia/Seoul +09:00                             |
| vehicleId / maxLoadKg / volume | vehicle_id / capacity_weight_kg / capacity_volume_m3 | ID·단위 유지, weight(ton)×1000과 대조                   |
| supportedItemTypes / inputYn   | supported_storage_types / available                  | enum 목록 / 0·1→bool                                    |
| shift_start / shift_end        | shift_start / shift_end                              | CSV에 +09:00 포함 근무시간 명시                         |

`priority=normal`과 06:00~18:00 근무시간은 시연 가정입니다. 희망시각과 시간창 시작,
센터·배송일 조회 필터, 좌표는 원본에서 별도로 보관합니다. `Order`의 필드로 임의 추가하지 않습니다.
조회 Tool 두 함수는 #29에서 인터페이스만 있으므로 실제 CSV 조회 연동 완료를 뜻하지 않습니다.
